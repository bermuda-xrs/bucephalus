# Original specification

`BUILD-SPEC.md` and `EXPLAINER.md` are the two documents this project was
built from, extracted unmodified from the `files.zip` the user supplied at
the start of the session. They are kept here, under version control, as the
permanent record of what "the spec" means when `INVARIANTS.md` or a commit
message refers to it.

Where this build deviated from the letter of the spec — and why — is
documented in [`../INVARIANTS.md`](../INVARIANTS.md).
